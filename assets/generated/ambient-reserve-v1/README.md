# 小店动态特效储备 · Ambient Reserve v1

**16 种效果 × 2 档强度 = 32 段动画，每段 8 帧，共 256 帧。** 另有 32 张水平帧条和 1 张完整图集。帧条和图集是相同帧的打包形式，不额外计为新动画或新造型。

原创程序化像素绘制，使用项目主色板，透明 PNG；不是模型生图。此包未注册到游戏，不改变互动奖励、天气、烹饪或存档。

预览默认遵循 `prefers-reduced-motion`，减少动态模式下暂停，允许手动播放。暂停时不会保持持续动画重绘。所有资源仅来自本目录，不读写 localStorage 或游戏存档。

## 内容

- 冲煮：杯口卷蒸汽、咖啡滴落、水壶热气、糖粒闪光。
- 天气：缓落秋叶、花瓣飘落、窗边小雪、雨滴涟漪。
- 室内：烛火轻摇、水面波纹、清洁泡泡、烘焙粉尘。
- 反馈：收入小闪光、爱心冒泡、轻音乐符、送达提示星。

轻柔/活跃档改变粒子数或结构，不只是换色。所有动画 8 fps、单轮 1000 ms；同一片段内没有完全重复帧。

## 技术规格与接入注意

- 单帧 64×64 美术像素，逻辑框 32×32，density=2；完整帧条 512×64，左到右帧 0..7。
- 锚点固定为 `(0.5, 0.875)`，即美术像素 `(32,56)`；实际挂载到杯口、地面或角色头顶时，需单独校准偏移。
- 全透明或全不透明，无隐藏脏 RGB；各帧四周至少 2 像素透明边距。通过块形和粒子分布变化表达运动，不依赖半透明渐变。
- 清单的 `loop` 必须遵守。收入闪光、爱心和送达提示是 `loop:false` 的单次反馈；预览页会在末帧停半秒后重演，仅为方便检查，不能把此行为直接当成生产事件重复触发。
- 生产接入时，应由事件只触发一次单次动画，不得因动画帧循环重复发钱、增加好感、结算订单或推进任务。
- 天气类贴图是小范围粒子样片，不是完整天气系统或屏幕覆盖图；需结合场景裁剪与层级复核。
- 只按需复制选中的片段进入生产目录。本目录不参与默认打包、服务工作线程预缓存或游戏启动加载。

## 可重复生成

在仓库根目录：

```sh
node scripts/build-ambient-reserve.mjs
node scripts/build-ambient-reserve.mjs --check
npx vitest run scripts/ambient-reserve.test.mjs
```

生成前先在内存检查全部帧；生成后解码回读每一帧、帧条和图集，与源绘制逐字节比较。输出清单记录 SHA-256，重建拒绝覆盖被手改的生成文件。修改应发生在生成器中；手改素材须先保留再重建。预览与本文档不受生成器覆盖。

机械验证不代替动画视觉审阅；原尺寸的粒子可读性、循环连接和场景实际速度需在最终使用位置复核。

# Tiny Bean Café · 小店素材仓库

这个目录是独立的美术储备浏览器。**所有资产仍是 reserve，未接入游戏玩法、商店、存档或默认加载。** 原创程序化像素绘制，不是下载素材，也不是生图模型输出。

## 打开

直接用浏览器打开 [统一画廊](index.html)，或者在项目现有开发服务器访问 `/assets/generated/reserve-library/index.html`。无需新开服务器、联网、安装插件或进入游戏。

画廊支持：

- 素材包、类别、季节组合筛选，以及中英文名称/标签/ID 搜索；
- 每页 48 张、图片懒加载，避免一次展示上千张图片；
- 1×/2× 像素预览和深色、浅色、透明棋盘背景；
- 单张 PNG 下载、稳定 ID 复制和各包透明图集/总览图下载；
- 跨页勾选后导出 JSON 待选清单。清单只包含引用和尺寸信息，不包含 PNG 字节，也不会自动接入游戏；
- `?pack=<pack-id>` 链接直接进入某一包。

选择只保存在当前页面内存，关闭页面即清空。没有 localStorage 或游戏存档操作。分享时请一起复制本目录及需要的兄弟素材包目录，路径保持不变。

## 重建和校验

从仓库根目录执行（Node 22，使用现有 PNG 编码器，不新增依赖）：

```sh
# 单独生成/验证一个新包
node scripts/build-reserve-library.mjs --pack=workshop
node scripts/build-reserve-library.mjs --pack=workshop --check
# 可用名称：workshop / neighborhood / hobby / travel

# 四个新包依次生成和验证
node scripts/build-reserve-library.mjs --all
node scripts/build-reserve-library.mjs --all --check

# 重建统一索引（只索引已经生成且有通过报告的包）
node scripts/build-reserve-library.mjs --gallery

# 生成器与画廊单元测试
npx vitest run scripts/reserve-library.test.mjs scripts/seasonal-reserve-gallery.test.mjs scripts/ambient-reserve.test.mjs

# 第一批有独立的生成器
node scripts/build-seasonal-reserve.mjs --check
```

四个新包的生成器在**写盘前**内存校验全部 192 张图；首次图像不合规不会留下半套输出。重建前会核对生成文件清单 SHA-256，拒绝覆盖被人工改动的 PNG/JSON/说明文档。请在绘制源模块中编辑，再重新生成；对产物的手工改动应先另存保留。

自动检查：原生尺寸、主色板、全透明/全不透明、透明 RGB 清洁、至少 3 像素边距、固定基线、不空白、无完全相同图片、每组 6 对非纯换色差异、48 个基础轮廓、图集逐像素回读、确定性源重绘、离线目录数据一致。统一索引另外比较所有包的稳定 ID 和解码后的像素哈希，防跨包重名与完全重复图。

## 使用边界

- 本目录及兄弟备用包不放在 public，不加入生产入口和离线预缓存。正常 `npm run build` 不发布备用库；不会拖慢游戏首次启动。
- 新包为 96×96 美术像素，density=2，逻辑目录框 48×48，固定锚点为美术 (48,90)。第一批锚点是 (48,88)，以各自清单为准。
- **目录画布不是实际游戏摆放尺寸。** 咖啡器具、街道家具和地标模型相对尺度不同，不应全都原尺寸直接塞入同一个房间。正式接入时应选择合适比例，重新按 2× 网格适配并校准接触点与遮挡。
- 固定锚点保证同一组变体目录预览不跳动，不代表所有物体都经过角色交互/桌面接触验收。
- 图集用于工程合批，总览图有不透明背景，仅用于挑图。
- 机械检查不能判断审美。大量图标化备用资产仍需人工筛选；与已上线场景一致的透视、材质和实际尺寸需要游戏内复核。
- 不改菜单价格、解锁条件、物品容量、动画状态机、存档或服务逻辑。此任务不部署、不提交、不推送用户已有改动。

## 离线整包与收尾复核

运行 `python3 scripts/package-reserve-library.py` 可创建 [完整离线压缩包](../../../artifacts/tiny-bean-reserve-library.zip)。解压后打开顶层入口页即可选择静态画廊或动画预览；压缩包包含 PNG、图集、索引、色板与说明，保留目录结构即可，无需网络和服务器。生成器留在完整项目仓库中，不混入美术分享包。

压缩包检查生成产物 SHA-256、ZIP CRC 和每个条目字节回读；固定条目顺序与时间戳，重复打包应得到相同哈希。压缩包本身也有哈希凭据，拒绝覆盖被人工改动的旧包。

独立视觉抽检已实际查看四个新静态包的总览及若干代表单件，并非逐件验收。重点修复并复看了夏季厨师机/摩卡壶、秋季小提琴、春季针线盒：工作机构、金属棱面、琴弦琴桥与盒内工具的可读性均有改善，四张未见截断。仍需注意小提琴弦桥、针线盒盖内的细节较密，大型家具与原场景的材质完成度和透视仍需正式接入时校准。

蒸汽已改连续卷曲线条；爱心尾帧缩小，改善突然消失。雨滴线条偏细、冬季踏石积雪表达较弱，保留为可选储备，不视为最终成品。

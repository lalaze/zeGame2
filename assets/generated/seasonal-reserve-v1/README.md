# 四季咖啡馆备用素材库 · Seasonal Reserve v1

这是 Tiny Bean Café 的**备用资产包**，不是已上线的家具、菜单或奖励。包内图像采用原创程序化像素绘制，生成逻辑保留在仓库中；未调用第三方素材库，也不包含 AI 生图模型的输出。

## 查看和挑选

- 直接在浏览器打开 [素材画廊](index.html)：可按类别、季节筛选，中英文搜索，切换浅色/深色/透明棋盘背景和 1×/2× 预览，下载单张 PNG、复制稳定 ID。
- 已启动项目开发服务器时，访问 `/assets/generated/seasonal-reserve-v1/index.html`。
- [总览图](contact-sheet.png) 便于快速挑选；[透明图集](atlas.png) 用于合批；[清单](manifest.json) 保存准确尺寸与图集坐标。
- [catalog.js](catalog.js) 是同一清单的本地浏览器版本，让画廊无须 `fetch`、服务器或网络即可运行。

**默认不放入 public、不参与 Vite 生产入口、不加入离线预缓存，也不增加游戏首次加载量。** `npm run build` 不发布这份画廊；如果需要给美术同事分享，将本目录整体复制即可，不能只复制单个 HTML。

## 素材方向

**本批共 192 张独立透明 PNG：48 种基础造型 × 春夏秋冬 4 个变体。** 六类各 8 种基础造型、32 张变体；另附 1 张透明图集及 1 张不透明总览图。不能将其表述为 192 种不同基础设计。

四季主题覆盖季节饮品、烘焙甜点、花植、礼盒与外卖、阅读角、节庆及猫咪日常小物。准确的基础造型、变体和类别数量以 [清单](manifest.json) 与 [验证报告](verification-report.json) 为准。

四季变体作为同一种物体的不同设计储备，不代表四种已实现玩法，也不是新增配方或解锁承诺。没有批量生成新角色动作，避免与现有角色身份、坐点和动画接口冲突。

## 技术约定

- 像素密度 `density: 2`，美术尺寸为逻辑尺寸的两倍。缩放采用 nearest-neighbor / `image-rendering: pixelated`。
- 使用 [项目主色板](../../../docs/art-grid/palette.json)，遵循 [世界美术规则](../../../docs/art-grid/README.md)：暖色细轮廓、左上主光、清晰材质块面，普通像素只允许全透明或全不透明。
- 每张保留透明边距，主体完整，接触阴影不延伸到画布边界。
- 清单的 `anchor` 是归一化坐标；`atlas` 坐标是图集中的物理美术像素，不能直接当游戏逻辑坐标。
- `status: reserve` 与 `integrated: false` 明确标识未接入状态。不要把生成清单整体当家具商店数据。

## 可重复生成与校验

在仓库根目录执行，不需要安装新依赖：

```sh
node scripts/build-seasonal-reserve.mjs
node scripts/build-seasonal-reserve.mjs --check
npx vitest run scripts/seasonal-reserve-gallery.test.mjs
npm run build
```

生成器仅更新本包的生成文件，不修改画廊和本说明；编辑图像应改生成器再重新运行，直接改 PNG 会在下一次生成时覆盖。校验包括 PNG 解码、尺寸、透明度、色板、透明边距、非空/非重复、图集坐标与逐像素一致性。测试覆盖画廊搜索、组合筛选、空结果、重置、缺失索引和复制降级。

## 将来接入游戏

1. 在画廊中挑选单件，复制其 ID，在清单中查找逻辑大小和锚点。
2. 将**选中的文件**复制到合适的生产素材目录，别把全库塞进预缓存。
3. 按实际用途注册到现有 canvas/Phaser 素材适配层，保持密度 2，不随意拉伸。
4. 用游戏现场验证光线、遮挡、脚底/摆放点和同类物体比例。统一画布只用于备用库整理，不代表所有物体应在游戏里显示成同样大小。
5. 若新增菜单、家具或奖励，另行实现配方/价格、双语文案、存档兼容和测试；本包没有这些行为。

## 验收边界

程序验证通过只说明文件和像素约定正确，并不等于每件已经通过游戏内视觉验收。尤其大型家具和小餐具需在真实场景中校准相对比例。本次不替换已有资源、不改玩法、不部署、不提交或推送用户已有改动。

- 独立审阅者实际查看总览、原项目风格样图及春季扶手椅、夏季茶杯、冬季猫窝、秋季花篮四张抽样，未见画布截断。

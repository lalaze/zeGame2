# Modular room candidates
22 independent transparent PNG modules. Original imagegen sources and exact lossless source_crop rectangles are retained. Alpha >128 is only a measurement threshold; crops retain every source RGBA pixel.

All are pending runtime review. Window/frame apertures were numerically inspected; recorded interior sample rectangles contain no opaque sky. Source edges can retain alpha 1 fringes. Reading window aspect differs from the logical envelope: preserve aspect and adapt placement, do not stretch. Main door frame has separate opaque door leaf. All signs are blank for runtime text. Dynamic sky, lights, stock, people and gameplay placement remain independent.

Main room reuses prior main-window, chalkboard, wall-lamp, counters. Floor/wall/counter material choices belong to decor batch. Kitchen equipment belongs to separate kitchen batch. These modules support all five area compositions but are not complete baked backgrounds or evidence of runtime integration.

reading-window-first-crop.png is rejected provenance only, superseded by reading-window-ochre.png. PROMPTS.json retains exact requests.

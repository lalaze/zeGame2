# UI and signature candidates
36 independent PNG candidates plus two upgrade aliases. Exact imagegen sources and lossless source_crop rectangles are preserved. Alpha>128 only measures bounds, never removes pixels. Images were inspected over an opaque background; hidden source RGB is not evidence of painted opaque backdrop.

Three staff icons follow existing upgradeIcon fixed looks: bun hairstyle, barista light skin/brown hair/green apron, server medium-brown skin/dark hair/blue apron/bowtie, cook tan skin/brown hair/white toque. They are upgrade portraits, not replacements for saved custom staff appearances.

Signature components are independently authored layers, not registered fixed-canvas layers. Cups have real transparent apertures. Liquids are surface ellipses, toppings are separate; glass liquid-body fill/clipping and exact dose-specific garnish composition remain an explicit gap/review requirement. A peaked milk cap is not a flat milk band. No claim that all signature combinations are complete. Runtime recipe semantics, quantities, progress and labels remain live.

All candidates await post-push renderer review. Tableware may require native-aspect fit; do not stretch source geometry. Full sources retain low-alpha fringes.

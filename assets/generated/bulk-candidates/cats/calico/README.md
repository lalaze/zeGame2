# calico — 14 action sprite pack

Generated with built-in image_gen. The complete exact prompt is in prompt.txt. source.png is the unmodified original source. Fourteen breed-action PNGs are lossless crops only. renderer-manifest.json includes source crop rectangle, alpha>128 bounding box, support-foot and headContact coordinates, one common scale for the source sheet, hashes, alpha statistics and explicit QA notes.

This pack is ready for the generation checkpoint and subsequent runtime QA, not yet runtime approved. No repo files were changed. Check game-scale legibility, route flip, head-to-hand contact, raised pose height, reduced motion and all 14 state mappings before final acceptance. Raised frames are naturally ~8–16% taller on the source sheet; do not normalize individual frame heights. If interactions require more height, regenerate tall poses or adjust authorized placement using contact anchors rather than stretching the cat.

Source and resulting crops preserve transparency. Threshold boxes exclude faint fringe; no alpha cleanup, repainting, recoloring or morphology changes were performed in code.

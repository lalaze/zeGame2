# persian — 14-action generated sprite pack

Original source sheets and exact prompts preserved. Fourteen named PNGs are lossless rectangular crops only. renderer-manifest.json identifies the selected source for each action, alpha>128 bbox, manual foot/crown-between-ears anchors and one calibrated scale per source sheet. Final correction sheets replace selected crowded/ambiguous original frames; original failed variants remain for provenance but are not selected by the manifest.

Built-in image_gen generated all visual content. No programmatic pixel edits, recoloring, alpha cleanup or per-frame resizing. Each final crop contains exactly one major alpha>128 cat component and pixel equality with its source rectangle was verified. Transparent fringe and any faint source halo are retained.

Generation checkpoint candidate, not runtime approved. Raised pose height should be evaluated from metadata and real contact, never per-frame fit.

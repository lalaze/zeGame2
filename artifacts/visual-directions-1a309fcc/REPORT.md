# 视觉方向实施验收（2026-10-15）

按已确认的方向实施：1A 手机默认全景、可缩放拖动；保留画风统一相对比例；店名开放玩家自定义。

## 已实现
- 默认依旧完整等比显示房间，不改变原房间长宽比或邻接房间预览。
- 双指缩放范围 1–3 倍，放大后单指拖动；提供放大、缩小、全景按钮。横竖屏/尺寸变化、切换房间与总览时恢复全景。
- 仅画布缩放，管理面板与按钮保持原触摸尺寸；拖动有 8 CSS 像素阈值，普通手抖不取消点击。双指、拖动、取消、房间/家具交互上下文变化不会提交家具点击。弹窗打开时取消进行中的手势。
- 人物保留原资源、衣服和身份。普通顾客站姿腿部延伸由 9 调为 4 个场景单位，样板顾客仍保留 9；店主/员工、坐姿与椅子组合未重绘。
- 主菜单牌显示现有 profile.cafeName，霓虹咖啡牌也使用该名字；功能文字按语言显示今日菜单、营业中/休息中、点单、取餐。
- 自定义店名继续使用创建咖啡馆及设置内“编辑资料”的已有入口；继续使用原存档字段和 20 码点清洗约束，没有新增平行名称字段。
- 场景文本使用原生 Unicode 字体和宽度量测，过长显示省略号，不横向挤压字形；HUD/设置保留完整名字。旧资料缺失仍走原创建流程。

## 边界与未覆盖
- 浏览器验证是主机隔离 Chrome 的触摸模拟，并非实体 iOS/Android 手机实测。
- 当前 HTTP 预览维持临时存档限制。本轮验证了内存序列化/反序列化与旧 profile 兼容；没有借此声称 HTTP 页面刷新后可恢复永久存档，也未改变任何安全设置。
- 人物为现有画风的比例调整，不是全套重绘；上述数值为抽样，不代表遍历所有外观组合。
- 本轮任务相关浏览器/测试命令均已退出。复用原预览服务，未另开监听、未停止其他服务。

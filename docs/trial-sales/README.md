# 新品试卖

在备店界面，从已拥有但未正式上架的饮品中选一款，包含保存的自创配方。每天最多制作 5 杯，玩家可以先观察口味反馈，再决定继续试卖或正式上架。

## 规则

- 只替换现有订单里的饮品位置：普通饮品顾客每第三位尝鲜，不创造额外客流；纯餐点订单不改。其他具名熟客保留原偏好。
- 常规菜单至少需要一道饮品才有试卖机会。保留常规菜单的开店、供应与关店规则；试卖是附加选择，不保证当天售完。
- 实际订单占一个名额，开始制作时消耗真实原料并计入当天成本。排队离开释放未制作名额；制作后未送达仍占名额和成本，不获得收入、口味反馈或熟练度。
- 补货预测在普通菜单的基础上加上最多 5 杯的原料预算，并按实际购买扣钱。试卖共用原料、员工和制作时间；原有客流与产能预测仍是估计值，额外原料不是销售承诺。
- 每次送达沿用原支付、口碑、风格和熟练度流程。报告只计试卖饮品的收入，含饮品自身适用的加成；组合餐中的餐点收入不混入。毛利只减已消耗的试卖原料，不重复扣款或发奖励。
- “喜欢／还不错／不合口味”使用既有顾客风味偏好，不代替包含等待体验的服务评分。自创名称用文本显示，并在历史报告中保存。
- 米娜未暂停、未完成试讲的奶香心愿会预留一个奶饮名额。她仍随正常客流来访，真正收到试卖奶饮才推进心愿；当天没来可能最多只制作 4 杯。
- 收店后清空当日安排，保留上次报告。“再试一天”显式重新选择；“正式上架”通过现有菜单接口，自创常驻菜单仍最多 3 款。历史报告不会自动改菜单或购买原料。

## 存档与边界

存档版本 21。旧档默认没有试卖。营业快照同时验证顾客的未制作／已制作标记与当日名额；刷新不能重置已经使用的 5 杯额度。运行快照缺失或无效时，只释放没有消耗原料的预订，保留已制作杯数与成本。

修改为另一配方、删除或正式上架所选饮品会清空备店试卖安排；改名仍保留同一配方。营业中不能更换试卖。制作中的试卖订单不会进入改换饮品的推荐事件。

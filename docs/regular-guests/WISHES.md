# 米娜的咖啡馆小地图

第一条熟客心愿把备店选择、实际交付、后续对话和店内纪念连接起来。米娜为咖啡馆准备一次试讲与一份小地图，作为原有学校路线图故事之外的补充，不改写或阻挡原来的五章。

## 玩家流程

1. 成功招待米娜至少一次后，在「熟客」中的米娜卡片或「准备菜单」看到心愿。入口默认折叠，不替玩家接受。
2. 闭店时选择安排：
   - 安静的桌子：主店已有的 1 号桌、两把椅子预留给米娜。她会堂食；其他客人使用其余桌位或外带。送达她的餐点后解除预留，不购买或生成桌位。
   - 奶香饮品：玩家自己上架并备好奶香饮品。米娜点饮品时优先选择一款有供应的奶香饮品，也接受含牛奶／奶油的自创配方；纯食品订单不强加饮品。缺货时照常点单，心愿保留。
3. 真正把餐点送到预留桌，或把奶香饮品交到米娜手中，才完成试讲。消费、出餐、评价全部使用正常服务流程。
4. 以后一个营业日再次成功招待米娜，她带来地图与对应选择的寄语。同一天多次购买不会提前拿到地图。
5. 地图自动挂在主店吧台前；熟客记录中可查看、收起、重新挂出。没有额外货币、小费倍率或可重复领取的奖励。

米娜保持原有客流周期，不额外生成来客或承诺当天必来。心愿没有现实时间期限；试讲前可在闭店时换方案或暂缓。原有章节、未读计数和阅读动作独立保留。略过对话也不会丢失结果，结算和熟客记录都可回看。

## 数据与集成

- `src/game/regular-wishes.ts`：选择、暂停、真实交付条件、地图展示和保存校验。
- `regular-guests.ts` 在既有唯一来访凭证校验之后记录心愿；同一交付不能重复推进。`sim.ts` 继续负责真实座位、原料、服务及收款。
- `state.ts` 保存版本为 20。旧档默认没有心愿，不根据历史销量补发地图。日期顺序、已认识的米娜与合理接待次数用于校验。
- 预留桌进入桌边产能估算，解除后恢复；奶香饮品仍是熟客偏好替换，普通客群预测依旧是估计。
- `ui/regular-wishes.ts` 的卡片复用于备店、熟客记录和营业对话；结算显示对应日的实际进展。
- 手绘地图和留座牌使用项目原生像素 canvas 绘制。地图共用一张图形，分支用不同线色和独立寄语；不占家具格、不增加舒适度。

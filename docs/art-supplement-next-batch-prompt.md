【任务2：顾客0坐着喝咖啡，输出一张四帧图集】
文件：customer-0-drink-right.png
每帧80×88像素，一行四帧，总画布320×88像素，无额外间距。
严格沿用向右坐姿参考中的人物与椅子。椅子保留在每帧中，大小和位置完全不变，不另加餐桌。
臀部坐点固定在单帧坐标(36,64)，脚底参考点固定在(36,84)，左上角为(0,0)。
四帧依次为：
1. 坐稳，手握奶油色小咖啡杯，杯子位于胸前偏下。
2. 弯曲手肘，将杯子举近嘴边。
3. 杯沿接触嘴部，小口饮用，杯子只轻微倾斜。
4. 手臂与杯子回落，接近第一帧，以便循环。
仅手臂、杯子、少量头部动作变化，身体、椅子和双脚不漂移。保留眼镜和五官，不让杯子遮住整张脸。

【任务3：咖啡师向右压粉，输出一张四帧图集】
文件：barista-tamp-right.png
每帧64×88像素，一行四帧，总画布256×88像素，无额外间距。
沿用参考咖啡师身份和服装，把完整人物等比整理到帧内，脚底参考点固定在(32,84)，四帧人物高度相同。

1. 一只手稳定小型咖啡手柄，另一只手持压粉锤准备。
2. 压粉锤下降至手柄粉碗。
3. 双手轻微施力压实，肩膀小幅下沉。
4. 压粉锤抬起，接近第一帧。
动作朝向画面右侧，工具保持能读懂的像素轮廓。只画人物和手持的小工具，不画咖啡机、吧台或地面。

【任务4：厨师向右揉面，输出一张四帧图集】
文件：chef-knead-right.png
每帧64×88像素，一行四帧，总画布256×88像素，无额外间距。
沿用参考厨师的帽子、发型、肤色和围裙，脚底参考点固定在(32,84)，人物比例与咖啡师协调。
四帧依次为：
1. 双手前伸，准备按揉。
2. 手臂向右前方推压，身体轻微前倾。
3. 手臂收回，做折叠面团的手势。
4. 回到接近第一帧的姿势。
双脚不动，帽子大小不变。只画人物的揉面动作，不画面团、料理台、盆或食材；面团和台面将由游戏独立叠加。
双手在四帧中围绕同一操作高度活动，便于与独立台面及面团对齐。

【统一风格与交付】
温暖像素美术，奶油色、蜂蜜木、胡桃木、鼠尾草绿、砖红和少量黄铜；人物身份色以各自参考图为准。

每组四帧必须是同一个角色，头身比例、服装、肤色、发型、椅子和脚底一致；每帧完整画在自己的格子内，不越界、不裁切，不添加文字编号或网格线。
输出透明背景PNG，不画棋盘格背景，无文字、无水印、无房间背景。
一次交付上述5个PNG文件，最好打包为ZIP。像素图集必须保持指定帧数、顺序和画布尺寸。
如果无法输出精确小尺寸，可另交整数倍放大的源图，但保持同样布局与锚点比例，并明确实际尺寸，不要通过模糊缩放伪装成目标尺寸。
不要批量扩展其他顾客或员工，本轮只制作这三位角色的动作样张。

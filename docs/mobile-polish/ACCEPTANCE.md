## 主要修复与实证

1. 地图进入布置不再隐藏操作栏；手机布置时临时展开画布，完成后回到原面板与合理焦点。
2. 导航改为清晰的三列两行，服务速度/关店/布置操作移到画布外；购买、房间、帮助等主要目标至少 44×44 CSS px。主流程及英中烘焙列表审计均无小于 44px 的可见按钮/summary。
3. 各宽度 document/body 宽度等于视口。最终烘焙面板 clientWidth/scrollWidth 分别为 345/345、375/375、415/415；长价格、预测和操作不再撑宽。
4. 列表不因普通刷新、相同标签点击而跳回顶部。实测装扮滚动 1861 → 同标签 1861 → 食材再返回 1861；390→1180→390 恢复至 1861。
5. 家具动作在释放时确认，拖动、多指、取消、越界、视角变化、失焦或弹窗阻断不提交。真实鼠标拖过挂钟未选中，正常点击才选中；非法地面位置显示红色预览与提示；挂钟收纳、再放置，购买多肉并合法移动通过。触摸取消分支由原生事件单元测试覆盖，并非物理触屏操作。
6. 数量输入失焦不再丢焦点，也不会在按住下个按钮时替换其 DOM。真实键盘输入 23，再按住 +5 鼠标按钮 600ms，最终 28，执行一次；输入 19 后 Tab，数值为 19、焦点在加号。原有 `fill()` 仅用于部分布局检查，不作为提交成功证据。
7. 长开店提示在手机布局中占独立行。实测提示底部 y=161，服务控制顶部 y=177.89，无遮挡；内容保留。
8. 360×320 缩短视口中名称输入、保存以及备餐数量与底部动作可达；720×390 横屏修正后面板有 173px 可滚动区域。桌面 1180px 控件恢复原位置，设置 Escape 和布置 Enter 返回正常。
9. 原生 Chromium 切换标签约 79 秒，返回时金额与当日收益保持，游戏时钟仅含切换/截图间的几秒；恢复前台后时钟和收入再次前进。六条主流程均验证刷新金额不变。
10. 390×720 实际云浏览器营业中采样 10 秒：599 个 rAF 间隔，中位/P95 16.7ms，>50ms 为 0，long tasks 为 0；没有为了“优化”而改游戏性能逻辑。

## 验证方法与边界

- 真正执行的是 dot 云电脑 Chromium 的鼠标、键盘、可见 UI、原生标签切换；360/390/430 是未发布 QA iframe 的 CSS 视口，不是手机硬件。
- DOM 尺寸/目标审计是辅助证据，不替代视觉检查；截图带有 Desktop Chromium viewport simulation 标识。
- 没有物理触摸、多指手势、OS 软键盘、iOS Safari、Android 浏览器动态地址栏、刘海/系统安全区的真机验证。visualViewport / dvh / safe-area 已实现或保留，并以单测、缩短视口和横竖布局检查覆盖可行部分。
- 小型家具本体属于像素画布对象，并不声称每个像素物件都有 44px 实体尺寸；手机布置扩大可用画布，动作按钮满足目标尺寸。真实手指精度仍需真机检查。
- 桌面性能数字不代表手机 GPU/低端硬件性能。最终浏览器日志抽样可见云扩展自身 metadata 错误，不据此认定游戏运行异常，也不声称抽样覆盖全部历史控制台。
- 全部测试为独立 origin 的测试存档。没有操作用户原预览存档，没有注入金额、存档或游戏时钟。一个高级烘焙测试馆通过正常经营与内置 4× 赚取解锁资金；六条正式首轮流程均为 1×。

## 追加修复：非活动标签跨断点滚动（P3）

后续独立审核发现原实现只转换当前标签，非活动标签仍保存旧容器的绝对滚动值。桌面菜单相对偏移 757，切到装扮再缩到 390px 后返回菜单，会误变为约 544.41。

已改为统一保存列表相对偏移，在目标滚动容器中加回当前前置高度；重绘使用相同规则。首次访问保持顶部，短列表按浏览器实际可滚动范围截断，后续保存实际位置。

- 新增 5 个回归测试：桌面→手机非活动标签、反向、反复变宽及头部变化、clamping 后重绘/返回、头部仍可见时的负相对偏移。
- 实现侧真实 UI：中文高级菜单桌面 1118 → 装扮 → 390px → 菜单，wrapper1323 − prefix205 = 1118；反向手机566 − 205 = 361 → 装扮 → 桌面菜单361。
- 独立审核原触发复验：桌面757 → 装扮 →390px →菜单，wrapper970 − prefix212.59375 =757.40625，差异小于1px，来自浏览器整数scrollTop量化。
- 独立反向恢复桌面757；360px恢复757.40625，430px恢复757.203125，均小于0.5px量化误差，复核无遗留确认缺陷。独立完整构建与预览产物逐文件一致。
- 最终全套更新为666 passed /6既有 skips，build通过。真实UI记录见 `logs/scroll-fix-ui.json`。

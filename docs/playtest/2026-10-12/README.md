# QA evidence timeline

- `REPORT.md` preserves the original, pre-fix full-feature playtest.
- `FIX-IMPLEMENTATION.md` records the three local UI changes and final automated checks.
- `FIX-VERIFICATION.md` records the targeted real cloud-browser retest and its limits.
- `fix-code-review.md` records the independent review and resolved findings.

The new price and funded tests use explicitly synthetic QA states on isolated origins. They are not player save files or evidence of natural progression. Mobile widths are desktop-browser CSS viewports, not physical-device certification.

This repository evidence set intentionally excludes full synthetic save fixtures, the disposable harness/generator, and temporary workspace-pointer files. Reports retain references to those materials for provenance; those references are not claims that the excluded files are committed here. No user-origin save or credential is included. Original and corrected screenshots remain separate so the historical findings are not overwritten.

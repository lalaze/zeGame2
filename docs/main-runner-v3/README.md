# Main café runner redesign

The main café's oatmeal T-shaped runner is now a muted sage woven carpet with ivory/ochre binding and small coffee-branch embroidery. Its horizontal aisle and entry stem share one textile; the default entrance mat is integrated into the stem. Purchased rugs keep their existing selection while using the new matching cross-aisle runner and doormat.

Generated with the **built-in image_gen tool** using the current main café screenshot as the style reference. [Complete prompt](../../assets/generated/main-runner-v3/prompt.txt), [original generated image](../../assets/generated/main-runner-v3/source.png), [production PNG](../../public/art/generated/main-runner-v3/runner.png) and [crop registration](../../assets/generated/main-runner-v3/crop.json) are saved in the repository. Packing only trims the transparent exterior; it does not redraw or recolor pixels.

The painter preserves the end embroidery and rounded binding, extending only the unornamented weave for different room heights. All artwork stays in the existing circulation footprint; the right-hand doorway sill remains visible. Other rooms retain their existing rugs.

Validation: production build passed; 25 existing room/passage/rug tests passed. Actual Chrome checks at logical room heights 240, 300 and 360 found zero transparent junction gaps and zero pixels outside the intended footprint. Desktop and 390×844 mobile screenshots were inspected; mobile scroll width is 390 and there were no uncaught browser errors.

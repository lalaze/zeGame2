# 经营体验修复验收

六项反馈均已实现：

- 研发：开局开放牛奶和糖，试饮缺货可直接购买所需整份原料；咖啡类招牌承接浓缩等级与口味技术，并有 25% 基础售价溢价。简单纯咖啡配方制作 1.2 秒，牛奶配方 1.8 秒；复杂配方仍需更多时间和原料。
- 路线：猫咪方向先接待一天寄养猫，可付正常领养费留下；烘焙方向先试卖邻店协作的 6 个餐包。每店每种体验只可领取一次，刷新和切换方向不会重置。寄养与样品在当天收工时结束，长期烘焙仍需后厨。
- 手机：标签改为单行，目标缩为可展开条，保留可领取奖励的展开状态和 44px 控件。定位时收起管理页、切换房间、居中放大 1.6 倍并高亮 6 秒；可返回原猫咪子页、滚动位置与按钮焦点。
- 补货：按钮与实际采购共用 `restockPlan`，购买前显示采购清单、实际支出、剩余现金及未满足需求。
- 时间：猫咪照料统一显示营业小时。售罄关门时先解释原因，并提供补货继续当天营业或今天收工；20:00 后不可续开当天。
- 生活反馈：主界面使用描述性的客流提示，精确周期保留在经营详情；天气的数值说明可展开。熟客抵店时每天提供一次可略过的交谈，工作伙伴的未读故事进入收工报告，只有明确读完才标记已读。

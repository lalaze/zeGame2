# Street scene sprites

Static first frames of existing café art, extracted with `node scripts/build-street-scene-art.mjs` (macOS sips). No new external artwork. Shop sprites: cozy-idle-v1; scenery and displays: cozy-world-v2 / cozy-furniture-v2; pedestrians: cozy-cast-v7; street furniture: neighborhood-reserve-v1 (original reserve-library art). PNG sheets animate only through CSS, disabled by prefers-reduced-motion.
